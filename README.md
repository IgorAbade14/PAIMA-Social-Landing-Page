# PAIMA Social - Portal Integrado de Engenharia

Este repositório foi desenvolvido como parte integrante do **Trabalho de Extensão Acadêmica** da disciplina de DevOps e Infraestrutura da **Faculdade Estácio Campus Queimados**, na disciplina **Programação Para Dispositivos Móveis em Android**. 

O projeto estende o conceito da plataforma corporativa original PAIMA, aplicando técnicas avançadas de infraestrutura e engenharia de software para resolver um problema real de impacto social e operacional.

## 🎯 Contexto do Projeto de Extensão

O estudo de caso foca na modernização da portaria da **COOPROGRESSO** (Cooperativa Regional de Transportes e Logística Comunitária). O objetivo principal é demonstrar a viabilidade técnica e financeira da transição de fluxos analógicos (papel/prancheta) para um ecossistema digital móvel resiliente, promovendo a inclusão digital dos operadores e a eficiência logística comunitária

A criação e planejamento foi feito pela minha perspectiva como Engenheiro DevOps, onde realizei o planejamento de todo o projeto e como ele iria funcionar, não possui versão fisica do projeto pois ele é totalmente conceitual, e criado por cima de outro projeto criado em 2024, para compreender melhor o projeto, abra e leia o pdf fixado do repositório junto com o fluxograma do sistema.

## 🏗️ Pilares Tecnológicos & DevOps Demonstrados

- **Abordagem Offline-First:** Arquitetura lógica detalhada para operação contínua utilizando cache local em SQLite embarcado, mitigando os riscos de instabilidade de rede em pátios periféricos.
- **Edge Computing:** Processamento de OCR (reconhecimento de caracteres) na ponta através do Google ML Kit no dispositivo Android, reduzindo custos com pacotes de dados.
- **Modelagem UML Dinâmica:** Diagrama de sequência automatizado com Mermaid.js integrado diretamente na interface para defesa e avaliação acadêmica.
- **Pipeline Interativo:** Blueprint de SRE que mapeia a jornada assíncrona do dado até a sincronização final no banco de dados Firebase Cloud DB.
